# Personal Finance Tracker

A simple command-line Personal Finance Tracker built with Python.

The application allows users to record and manage their income and expenses,
track their financial balance, generate monthly expense reports, set category
budgets, create expense visualizations, and back up their financial data.

The project was developed using fundamental Python concepts such as functions,
loops, conditional statements, dictionaries, file handling, CSV processing,
input validation, and exception handling.

---

## Features

### Income Management

- Add income records
- Store the income amount, source, and date
- View all income records
- Calculate total income

### Expense Management

- Add expense records
- Store the expense amount, category, and date
- View all expense records
- Calculate total expenses
- Organize expenses by category

### Financial Summary

The application calculates:

- Total income
- Total expenses
- Current balance
